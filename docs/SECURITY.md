
# Security Policy

## Current Status

AI Compute Fabric is currently a development and portfolio project and should not be considered production-secure.

The current implementation does not provide:

- authentication
- authorization
- TLS termination
- persistent secure storage
- secrets management
- workload isolation
- network policy enforcement

## Reporting a Security Issue

Please do not publicly disclose sensitive security issues before they can be investigated.

For the current development project, security issues should be documented privately to the project maintainers.

## Future Security Goals

Production hardening will include:

- authentication
- role-based authorization
- secure API communication
- secrets management
- workload isolation
- audit logging
- network policies
- least-privilege access
- secure GPU workload execution
